# Cutora Fresh (GodaCut)

A premium Swiggy-inspired e-commerce application for fresh meat and groceries.

## Features
- **Modern UI**: Built with React, Vite, and Tailwind CSS.
- **Premium Aesthetics**: outfit font, custom animations, and glassmorphism.
- **Precision Ordering**: Dynamic pricing for "Uncut" and "Cut & Clean" options.
- **Admin Dashboard**: Comprehensive order and product management.
- **Order Tracking**: Real-time status updates and WhatsApp integration.

## Tech Stack
- Frontend: React (Vite)
- Styling: Tailwind CSS, Framer Motion
- State Management: Zustand
- Backend: Supabase

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`
